# Dotfiles
Dotfiles collection.

## Setup (\*nix)
```
git clone https://github.com/tupl-dev/dotfiles
cd ./dotfiles && /bin/sh ./init.sh
```

## Setup (Windows)
```
git clone https://github.com/tupl-dev/dotfiles
cd ./dotfiles && ./init.ps1
```

## Others
- Install [`oh-my-posh`](https://ohmyposh.dev/docs)
- Install [`oh-my-zsh`](https://ohmyz.sh/#install)
